# Punch Point

A low-cost, portable braille embosser for teachers of blind and low-vision students, designed by a MedLaunch UIUC team.

- [Test rig viewer](https://b-47.github.io/punch-point/concepts/test-rig/viewer/)

  ![Test rig: the solenoid drives the stylus up through the paper into the die](concepts/test-rig/media/strike.gif)

- [Six-solenoid head viewer](https://b-47.github.io/punch-point/concepts/six-solenoid-head/viewer/)

  ![Six-solenoid head embossing "punch" one braille cell per strike](concepts/six-solenoid-head/media/emboss.gif)
